# 📈 Pulse Analytics — Tableau de bord commercial (Superstore)

Tableau de bord interactif développé avec **Python** et **Dash**, conçu pour analyser les performances commerciales d'une entreprise à partir du dataset Superstore (Kaggle) : chiffre d'affaires, profit, ventes par région et par catégorie.

## 🎯 Objectifs

- Offrir une vue d'ensemble claire des performances commerciales pour aider à la prise de décision
- Permettre une analyse filtrée par période, région, catégorie de produit et segment client
- Identifier les produits et régions les plus rentables

## ✨ Fonctionnalités

- **4 KPIs** : chiffre d'affaires, profit, nombre de commandes, nombre de clients
- **4 filtres** : année, région, catégorie, segment client
- **5 visualisations** :
  - Évolution du chiffre d'affaires et du profit dans le temps
  - Top 10 des produits les plus vendus
  - Carte des ventes par état (USA)
  - Répartition des bénéfices par catégorie
  - Analyse Pareto des produits (règle des 80/20)
- Sidebar avec logo dédié ("Pulse Analytics") et design professionnel type tableau de bord d'entreprise

## 🛠️ Technologies

- Python
- Dash / Plotly
- Pandas

## 📊 Jeu de données

- Superstore Dataset (Kaggle — vivek468/superstore-dataset-final)
